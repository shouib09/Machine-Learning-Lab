# Machine-Learning-Lab-Experiments

This repository contains Machine Learning laboratory experiments implemented using **Google Colab**. Each experiment includes source code, datasets (if required), outputs, and result analysis.

## Tools Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

1. FIND-S Algorithm
2. Candidate Elimination Algorithm
3. ID3 Decision Tree
4. Artificial Neural Network (Backpropagation)
5. K-Nearest Neighbors (KNN)
6. Naïve Bayes Classifier
7. Logistic Regression
8. Linear Regression
9. Linear vs Polynomial Regression
10. Expectation Maximization (EM) Algorithm
11. Credit Score Classification
12. Iris Flower Classification using KNN
13. Car Price Prediction
14. House Price Prediction
15. Iris Flower Classification using Naïve Bayes
16. Comparison of Classification Algorithms
17. Mobile Price Prediction
18. Perceptron-based Iris Classification
19. Bank Loan Prediction using Naïve Bayes
20. Future Sales Prediction

## Objective
To understand and implement fundamental machine learning algorithms through practical experiments and performance analysis.
